- 训练期 2×费用：20/20 为正；
- 2025 验证：15/20 为正；

这表明 V3 对币种集合和市场阶段都不稳定。

## 6. 盈利导向结论

V3.1 是目前最值得继续观察的研究候选，因为它：

- 在未参与设计的市场阶段中承受了 3×费用；
- 把实现 BTC beta 压低到 -0.05；
- funding 为负时仍有正收益。

但它尚不适合投入资金，因为：

- -35.8% 回撤会严重破坏复利；
- alpha t 值仅 1.06，统计证据不足；
- 2022 年已经转亏；
- 利润依赖少数币和少数月份。

当前“盈利最大化”的实际资金决策仍是 0 权重。不能通过降低门槛、事后降杠杆或删除亏损币种把 V3.1 包装成通过。
